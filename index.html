Konsistensi per outlet

Outlet yang dikunjungi lebih dari sekali dinilai konsistensinya berdasarkan Flag Radius seluruh kunjungan. Tag ini muncul di kolom Konsistensi tabel.

Konsisten Valid

Semua kunjungan outlet ini Flag = 1 (IN RADIUS). Tidak ada aksi.

Konsisten Bermasalah

Semua kunjungan outlet ini Flag = 0 (OUT RADIUS) atau BLANK. Perlu revalidasi.

⚠ Inkonsisten

Kadang IN RADIUS, kadang OUT RADIUS / BLANK di outlet yang sama. Sinyal: koordinat borderline / validasi salah / sales tidak konsisten. Prioritas investigasi.

Langkah kerja & permintaan data
  1. Masing-masing SS tarik EDI Flag Visit Radius di Matriks, minta sama SA.
  2. Tambahkan Nama Toko, Alamat Toko, Rayon, Cycle, HHT.
  3. SS filter Flag BLANK & 0 → belum validasi dan out radius.
  4. Cocokan LongLat Validasi, LongLat Last Visit, dan Alamat Toko.
  5. Validasi salah & last visit juga salah → validasi ulang. Kalau last visit benar → Atribut 4.
  6. Validasi benar tapi last visit salah (sales tidak kunjungi, order by phone) → orderan by FPB KPL, jangan input SFA.
  7. Permintaan data: LongLat Last Visit, LongLat Validasi, Kode Outlet, Nama Toko, Alamat Toko, Nama Salesman, Rayon, Cycle, HHT/Scan, Jam Masuk, Jam Keluar, Flag Radius, Alor Reason.
